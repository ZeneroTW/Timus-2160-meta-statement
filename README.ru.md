# 🌳 Подсчёт эквивалентных шаблонов перестановок — декартово дерево + комбинаторика

> 🇬🇧 [Read in English](README.md)

Решение задачи **Timus 2160 «Мета-условие»**: по данной перестановке посчитать, сколько других перестановок ей *эквивалентны* при рекурсивном определении шаблона через минимум. Наивный подход даёт O(N · N!); здесь задача сводится к **изоморфизму декартовых деревьев** и решается за **O(N)**.

Задача принята на Timus со временем **1.14 с** и памятью **39 МБ** при N до 10⁵.

---

## Задача

Жюри расставляет N задач в контесте по сложности (1 — самая сложная), используя *шаблон* — перестановку чисел от 1 до N. Шаблон интерпретируется рекурсивно: найти минимум, разбить массив на левую и правую часть, повторить для каждой части.

Два шаблона **эквивалентны**, если оба пустые, либо у них совпадает позиция минимума и их левые и правые подшаблоны эквивалентны.

| Свойство     | Значение              |
| ------------ | --------------------- |
| Вход         | N, затем p₁ … pₙ      |
| Ограничение  | 1 ≤ N ≤ 10⁵           |
| Выход        | Ответ по модулю 10⁹ + 7 |
| Время        | 2 с                   |
| Память       | 256 МБ                |

### Примеры

| Вход            | Ответ |
| --------------- | ----- |
| `3` `2 1 3`     | 2     |
| `5` `3 1 4 2 5` | 8     |

Перебор «в лоб» не подойдёт: перебрать все N! перестановок и проверить каждую — это O(N · N!), уже при N = 20 около 2.4 · 10¹⁸ операций.

---

## Идея

Шаблон — **это** декартово дерево. Корень — минимум массива, левое и правое поддеревья строятся рекурсивно из элементов слева и справа от него.

```
(3, 1, 4, 2, 5)          1
                        / \
                       3   2
                          / \
                         4   5
```

В декартовом дереве сочетаются два свойства одновременно — BST по позициям (слева направо = исходный массив) и min-heap по значениям (сверху вниз значения только растут, корень — глобальный минимум). По массиву с уникальными значениями строится однозначно.

**Эквивалентность ⟺ изоморфизм деревьев.** Два шаблона эквивалентны тогда и только тогда, когда у их декартовых деревьев совпадает форма без учёта значений.

```
(2, 1, 3) и (3, 1, 2)  →  одинаковая форма  →  эквивалентны
(1, 2, 3)              →  другая форма      →  не эквивалентен
```

---

## Решение

Количество перестановок, дающих данную форму дерева, — произведение по всем вершинам:

```
ответ = Π C(L + R, L)  mod 10⁹ + 7
```

где **L** и **R** — размеры левого и правого поддеревьев вершины. Смысл: L + R значений под вершиной нужно распределить между двумя поддеревьями, и выбор того, какие L из них уходят влево, полностью задаёт расстановку.

Разбор для шаблона (3, 1, 4, 2, 5):

| Узел | L, R  | C(L+R, L)  |
| ---- | ----- | ---------- |
| 1    | 1, 3  | C(4,1) = 4 |
| 3    | 0, 0  | 1          |
| 2    | 1, 1  | C(2,1) = 2 |
| 4    | 0, 0  | 1          |
| 5    | 0, 0  | 1          |

Произведение = 4 · 1 · 2 · 1 · 1 = **8**.

## Реализация

### Построение дерева за O(N) — монотонный стек

Идём по массиву слева направо, в стеке держим узлы по возрастанию значений снизу вверх. Для каждого нового `x`:

1. пока вершина стека больше `x` — выталкиваем; последний вытолкнутый становится левым потомком `x`
2. если стек не пуст — `x` становится правым потомком новой вершины стека
3. кладём `x` в стек

Каждый элемент входит в стек и выходит ровно один раз → O(N). Корень — дно стека.

### Биномиальные коэффициенты по модулю простого

По модулю нет обычного деления — нужен обратный элемент. Так как p = 10⁹ + 7 простое, по малой теореме Ферма `a⁻¹ ≡ a^(p−2) (mod p)`, что считается за O(log p) быстрым возведением в степень.

Факториалы и обратные факториалы предвычисляются один раз:

- `fac[i] = i! mod p`
- `invfac[i]` через рекуррентность `(k−1)!⁻¹ = k!⁻¹ · k` — один `pow` на старте, дальше всё за O(N)

После этого любой `C(n, k) = fac[n] · invfac[k] · invfac[n−k]` считается за **O(1)**.

## Архитектура

Программа состоит из четырёх классов:

| Класс           | Ответственность                                                       |
| --------------- | --------------------------------------------------------------------- |
| `Node`          | Узел декартова дерева — `value`, `left`, `right`, `size_val` (размер поддерева) |
| `Stack`         | Стек на списке — `push` / `pop` / `top` / `is_empty`                   |
| `Combinatorics` | Предвычисленные `fac[]` / `invfac[]`, `C(n, k)` за O(1)               |
| `CartesianTree` | Оркестратор алгоритма — `build()` за O(N), `count()` = Π C(L+R, L)    |

### Грабли: рекурсия по дереву

На отсортированном входе декартово дерево вырождается в линейную цепочку глубины N. При N = 10⁵ рекурсивный обход переполняет стек вызовов и завершается аварийно.

Поэтому все обходы дерева — **итеративные**, через явный список-стек. Глубина теперь ограничена размером кучи, а не системного стека.
